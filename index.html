Data otomatis tersimpan permanen ke Google Sheets Anda & sinkron real-time ke semua HP.

Mode Lokal
Status: Terhubung ke Google Sheets
Buka Google Sheets ↗
Langkah Membuat Database Google Sheets Otomatis:
  1. Buka sheets.google.com dan buat Spreadsheet baru (misal: Database POS Mashita).
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus kode bawaan, tempel kode dari file Code.gs (atau klik tombol salin di bawah), lalu Simpan.
  4. Klik Terapkan (Deploy) → Deployment baru → Aplikasi web.
  5. Atur Jalankan sebagai: Saya dan Yang memiliki akses: Siapa saja (Anyone), lalu klik Terapkan.
  6. Salin URL Aplikasi Web dan tempel pada kolom di atas. Selesai!
